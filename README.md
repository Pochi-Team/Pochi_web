# Pochi_web
Pochi (Patient Oriented Care &amp; Health Intelligence) es un robot asistente de medicamentos para adultos mayores. Busca al paciente con una pulsera BLE, pregunta si va a tomar su medicina, dispensa la pastilla correcta y registra el historial de tomas. Proyecto de feria científica, Colegio Capouilliez, Guatemala 2026.
